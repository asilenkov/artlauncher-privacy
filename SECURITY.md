# Security Policy

## Supported versions

Security fixes are provided for the latest released version of ArtLauncher.
At present that is the `v2.4.x` line (`versionCode 29` / `2.4.2`).

## Reporting a vulnerability

Preferred channel: GitHub private vulnerability reporting on this repository
(**Security → Report a vulnerability**). If it is not enabled, open a public issue
**without sensitive details** and ask for a private contact method.

Please include:

- affected app version and device / Android version;
- steps to reproduce and the observed impact;
- whether a special permission or opt-in feature is involved.

Do not attach logs, screenshots or dumps containing personal notifications, contacts,
photos, location history or credentials. We aim to acknowledge a report within seven
days and will coordinate disclosure before any public discussion.

## Scope

This repository hosts the public privacy policy. Reports about the ArtLauncher app,
its permissions, its on-device data handling or its Google Play listing are welcome here;
the application source repository is private.
